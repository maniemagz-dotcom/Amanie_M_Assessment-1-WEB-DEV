Welcome to a Quick Reference Guide for HTML and CSS!

HTML Tags

Headings

The use of <h1> to <h6>are used to define the HTML headings by six levels.

Example:

                        
                            <h1> Main heading </h1>
                            <h2> Headings </h2>
                            <h3> Sub-sections </h3>

Paragraphs

The HTML <p> tag is used for paragraph content.

Example:

                        
                            <p> I'm a paragraph. </p>
                            <p> I'm another paragraph. </p>

Hyperlink

The HTML <a> tag is used to link from one page to another.
It uses href attribute to indicate the link's destination.

Example:

                        
                            <a href="https://www.google.com" target="_blank">Say hi to Google!</a>

Lists

There are two common types of HTML lists:

  • <ul> - unordered list used for bulleted points by default.
  • <ol> - ordered list marked with numbers by default.

Both of which uses <li> for each list item.

Example:

                            
                                <ul>
                                    <li> I'm a bullet point. </li>
                                    <li> I'm another bullet point. </li>
                                </ul>
                                <ol>
                                    <li> I'm list number one. </li>
                                    <li> I'm list number two. </li>
                                </ol>

Images

The HTML <img> tag is used to add images to your website.
It has two required attributes:

  • src - To specify the path of your image either embeded URL or local path on your computer.
  • alt - To specify an alternative text for the image when the web browser coudn't find your image.

Example:

                        
                            <img src="cat.gif" alt="Cat Dancing"> 
                            <img src="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcRN2z0ERwXQUqH29urPuzWueLXKhJAY6SMyAA&s" alt="Golden Retriever smiling">

Div

The HTML <div> tag is used as a generic container for other HTML elements and comes with line breaks.

Example:

                        
                            <div>
                                <h2> Golden Retriever </h2>
                                <img src="dog.jpg" alt="Golden Retriever smiling">
                                <p> A Golden Retriever is a Scottish breed of retriever dog.</p>
                            </div>

Header

The HTML <header> is a semantic tag that defines a header for a document or section.

Example:

                        
                            <header>
                                <h1> Main Heading </h1>
                                <p> Version by Winnie </p>
                            </header>

Main

The HTML <main> tag used for main content of the document.

Example:

                        
                            <main>
                                <h2> Most Adorable Dogs </h2>
                                <p> This includes Golden Retrievers and Samoyed dogs. </p>
                            
                                <article>
                                    <h2> Golden Retriever </p>
                                    <p> A Golden Retriever is a Scottish breed of retriever dog. </p>
                                </article>

                                <article>
                                    <h2> Samoyed </p>
                                    <p> Samoyed is a breed of herding dog with a thick, white, double-layered coat. </p>
                                </article>
                            </main>

Article

The HTML <article> tag specifies independent content.

Example:

                        
                            <article>
                                <h2> Samoyed </p>
                                <p> Samoyed is a breed of herding dog with a thick, white, double-layered coat. </p>
                            </article>

Code

The HTML <code> tag is used to define a piece of computer code, just like how the examples in this webpage was created!

Example:

                        
                            <p> This is a text and this <code>background-color</code> is a CSS property code.</p>

CSS Properties

Background-color

background-color is a CSS property used for changing the background color.

Example:

                        
                            p {
                                background-color: #f0f4ff;
                            }

Border Radius

border-radius is a CSS property used to change the rounded corners.

Example:

                        
                            p {
                                border-radius: 4px 5px 4px 5px;
                            }

Border Shadow

border-shadow is a CSS property used to add shadow to an element.

Example:

                        
                            div {
                                box-shadow: 10px 15px 15px 2px #000000;
                            }

Font Family

font-family is a CSS property used to add font to an element.

Example:

                        
                            h1 {
                                font-family: Georgia, serif;
                            }

Text Shadow

text-shadow is a CSS property used to add shadow to a text.

Example:

                        
                            h1 {
                                font-family: Georgia, serif;
                                text-shadow: 2px 2px 2px #1C6EA4;
                            }

Text Align

text-align is a CSS property used to align your text.

Example:

                        
                            h1 {
                                font-family: Georgia, serif;
                                text-shadow: 2px 2px 2px #1C6EA4;
                                text-align: center;
                            }

Outline

outline is a CSS property used to draw an outer border around elements.

Example:

                        
                            div {
                                box-shadow: 11px 16px 14px 2px #000000;
                                outline: 5px solid #1C6EA4;
                            }

Transform

transform is a CSS property used to 2D 3D transformation.

Example:

                        
                            div {
                                box-shadow: 11px 16px 14px 2px #000000; 
                                outline: 5px solid #1C6EA4;
                                transform: translate(14px, -10px);
                            }
